### Kurulum
1. [SuperBLT](https://superblt.znix.xyz/) kurulu olmalı (PAYDAY 2 klasöründe `WSOCK32.dll`).
2. [Releases](../../releases) sayfasından son `PPR_Improved_Edition_vX.Y.Z.zip` dosyasını indir.
3. PAYDAY 2'yi kapat. Steam'de PAYDAY 2'ye sağ tıkla, sonra Yönet > Yerel dosyalara göz at.
4. Eski bir PPR sürümü varsa `mods` klasöründeki eski `[MOD] Pirate Perfection Reborn Trainer! Patron Edition` klasörünü sil (ayarlarını korumak istersen önce yedekle).
5. Zip'in içindeki `mods` klasörünü PAYDAY 2 klasörüne kopyala.
6. Oyunu aç: ilk açılışta Türkçe / English seçimi çıkar. **F5** Ana Menü'yü, **F1** yardımı ve tuş listesini açar.

Eski ayarlarını korumak için yedeğindeki `Trainer\configs` klasörünü yenisinin üzerine kopyalayabilirsin.

## English

### Highlights
- **Full English and Turkish interface.** The language is picked on first launch and can be changed instantly in F5 > Language.
- **F5 hub:** every menu, the quick cheats and "turn every cheat off" in one place.
- **Key bindings (v3.2):** change any trainer key in game. Bind quick cheats to their own key and switch them with one press.
- **Teleport points (v3.2):** save spots on every map and teleport back. Undo the last teleport. Teleport to a crew member or to a waypoint.
- **Cheat profiles (v3.2):** save which cheats are on and switch them on together. A profile can also start by itself with every heist.
- **Active cheats list on screen.** It turns red on someone else's lobby.
- **Works with the current game:** all code was compared with PAYDAY 2's current source code and broken features were fixed. See [CHANGELOG.md](CHANGELOG.md).
- **Resilient:** if a game update breaks one feature, the rest of the trainer keeps working.
- **Safe:** the trainer connects to no website and has no auto-update.

### Install
1. Install [SuperBLT](https://superblt.znix.xyz/) (`WSOCK32.dll` in the PAYDAY 2 folder).
2. Download the latest `PPR_Improved_Edition_vX.Y.Z.zip` from [Releases](../../releases).
3. Close PAYDAY 2. In Steam, right-click PAYDAY 2, then Manage > Browse local files.
4. If you have an older PPR, delete the old `[MOD] Pirate Perfection Reborn Trainer! Patron Edition` folder in `mods` (back it up first to keep your settings).
5. Copy the `mods` folder from the zip into the PAYDAY 2 folder.
6. Start the game: the first launch asks for Türkçe / English. **F5** opens the hub, **F1** opens help and the key list.

To keep your old settings, copy `Trainer\configs` from your backup over the new one.

### Turkish characters
The game's fonts cannot show ğ, ş, ı and İ. That is why the default **safe** mode writes them as g, s, i and I (ç, ö and ü show fine). F5 > Language switches to **full** mode (all letters) or **ASCII** mode (no Turkish characters at all).

### Left out on purpose
This edition has no DLC unlocker, paid skin unlocks, safe simulator, loot card spoofing, item copying, anti-cheat or ownership verification bypass, mod hiding, "not modded" lobby, name spoofing, equipment-detection evasion, troll menu or PvP mode. These affect the game's paid content or other players.
